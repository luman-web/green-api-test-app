# WhatsApp Chat на GREEN-API

Минималистичный React-интерфейс для отправки и получения текстовых сообщений в WhatsApp через GREEN-API.

## Возможности

- подключение по `idInstance` и `apiTokenInstance`;
- создание чата по международному номеру телефона;
- проверка номера методом `CheckWhatsapp`;
- отправка текста методом `SendMessage`;
- получение сообщений через очередь `ReceiveNotification`;
- подтверждение обработки методом `DeleteNotification`;
- обработка статусов отправки, доставки и прочтения;
- локальное сохранение чатов и сообщений по `idInstance`;
- адаптивный интерфейс и обработка ошибок API.

## Требования

- Node.js 20 или новее;
- авторизованный WhatsApp-инстанс GREEN-API;
- в настройках инстанса включены входящие уведомления;
- поле Webhook URL оставлено пустым, поскольку приложение использует HTTP API polling.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте адрес Vite и введите данные инстанса из личного кабинета GREEN-API.

По умолчанию используется общий API-хост `https://api.green-api.com`. При входе можно указать индивидуальный API URL инстанса из кабинета GREEN-API.

## Проверки

```bash
npm test

```

## Проверка полного сценария

1. Авторизуйте WhatsApp-инстанс в личном кабинете GREEN-API по QR-коду.
2. Включите получение входящих сообщений и файлов.
3. Введите в приложении `idInstance` и `apiTokenInstance`.
4. Создайте чат, указав номер WhatsApp в международном формате.
5. Отправьте текстовое сообщение и ответьте на него из WhatsApp.
6. Ответ должен автоматически появиться в веб-чате.

Для HTTP polling у инстанса должны быть установлены `incomingWebhook: "yes"` и
пустой `webhookUrl`. Приложение проверяет эти параметры и показывает кнопку
«Включить», если получение входящих сообщений отключено. Применение настроек
перезапускает инстанс и может занять до пяти минут.

## Архитектура

- `src/api/greenApiClient.ts` — HTTP-клиент и преобразование ошибок;
- `src/api/notificationParser.ts` — разбор входящих уведомлений;
- `src/hooks/useNotificationPolling.ts` — последовательная обработка очереди;
- `src/App.tsx` — экраны подключения и чата;
- `src/storage/chatStorage.ts` — сохранение чатов и сообщений в браузере;
- `src/utils/phone.ts` — нормализация и проверка номера.

Polling выполняется последовательно. Уведомление удаляется из очереди только после успешной обработки на клиенте.

## Безопасность

Токен существует только в памяти вкладки и не сохраняется в `localStorage`. Чаты и сообщения сохраняются локально в браузере отдельно для каждого `idInstance`;
